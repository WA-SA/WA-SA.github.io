# 国库券(Treasury Bills,T-Bills)

## 定义
**国库券 = 期限 ≤ 1 年的短期 [[国债]]。** 英文 **Treasury Bills(T-Bills)**。

它最大的特点是**不付 [[票息]]**:采用**折价发行**——比如以 98 元买入、到期按面值 100 元兑付,那 2 元差价就是你的收益(隐含利率)。所以它是一种**零息(贴现)工具**。

- 常见期限:4 / 8 / 13 / 17 / 26 / 52 周。
- 因为期限短、信用极佳,被当作**最接近"现金"的安全资产**,是货币市场基金、银行流动性管理的核心持仓。

## 与 [[国债]](中长期)的对比
"国库券"是国债家族里**最短的一档**;和中长期国债(T-Notes / T-Bonds)的区别:

| | **国库券(T-Bills)** | **中长期国债(T-Notes / T-Bonds)** |
|---|---|---|
| 期限 | ≤ 1 年 | 2–30 年 |
| 付息 | **无票息**,折价发行 | **半年付 [[票息]]** |
| 利率风险 / [[久期]] | 极低(近似现金) | 较高,久期长 → 价格对利率敏感 |
| 带 [[期限溢价]]吗 | 几乎没有 | 有,且越长越明显 |
| 典型角色 | 流动性 / 类现金 | 配置久期 / 赚长端 [[利率]] |

一句话:**国库券是"短钱工具"(贴现、像现金),中长期国债是"久期工具"(带票息、吃期限溢价)。**

## 为什么这里关键
- 美联储 2025 年底停止缩表后,Desk 做的"准备金管理购买"**专挑国库券买**(初期约 400 亿/月)——因为买短钱补流动性、又不想压长端(见 [[美联储准备金框架]] 发展史)。
