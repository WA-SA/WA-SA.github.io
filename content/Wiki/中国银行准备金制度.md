# 中国银行准备金制度(存款准备金率 / RRR)

> 指中国(商业)银行的**存款准备金制度**,由中国人民银行(PBoC)管理。注意"中国银行"此处指"中国的银行体系",非指中国银行这家商业银行。

## 定义
**商业银行必须把吸收存款的一定比例,以准备金形式上缴央行,这个比例就是"法定存款准备金率"(Required Reserve Ratio, RRR)。**

- **降准**(下调 RRR)= 把被锁住的钱放出来 → 银行可放贷资金增加 → **释放流动性**;
- **升准**(上调 RRR)= 回收流动性。
- **差别化**:大型银行 RRR 通常高于中小银行;PBoC 常用**定向降准**支持小微 / 三农。
- 央行对**法定准备金**(及超额准备金)付息,但利率较低。
- 趋势:历史上一度 20%+(2011 前后),此后**多次降准**,近年加权平均降到约 **6–7%**(以央行最新公告为准)。

## 与 [[美联储准备金框架]] 的对比
| 维度      | 中国(RRR 制度)                   | 美国(充足准备金框架)                                          |
| ------- | ---------------------------- | ---------------------------------------------------- |
| 准备金要求   | **法定 RRR**,强制、按存款比例上缴        | **2020 年 3 月起法定要求降为 0**;靠"充足"水平自然形成                  |
| 是不是活跃工具 | **是**,降准/升准是头条级常规工具(**数量型**) | **否**;准备金的"量"由 QE/QT(资产负债表)决定,不靠调比率                  |
| 怎么控利率   | 多工具组合:OMO 逆回购、MLF、LPR + 数量调控 | 主要靠**管理利率**([[IORB]]、[[ON RRP]])的"[[地板系统]]"(**价格型**) |
| 调控哲学    | 数量调控仍重,带信贷额度 / 定向色彩          | 价格调控为主,更市场化                                          |

## 核心区别(一句话)
- **中国**:把"准备金比率(RRR)"当成一个**主动、频繁拨动的总闸门**——降准=放水,是常规头条政策(数量型);
- **美国**:基本**取消了法定准备金要求**(2020 归零),准备金的"量"改由**资产负债表(QE/QT)**决定,利率靠**管理利率**控制;美国说的"[[美联储准备金框架|充足]]"指的是这个**量的状态**,而**不是**一个要银行遵守的比率。

换句话说:**中国调的是"比率(闸门开多大)",美国调的是"总量(印多少/收多少)";一个是规则约束,一个是资产负债表结果。**
