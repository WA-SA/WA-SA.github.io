# 泰勒规则(Taylor Rule)

## 公式
> **i = r\* + π + 0.5 (π − π\*) + 0.5 (y − y\*)**

- **i** = 应该设的政策 [[利率]](名义)
- **r\*** = [[中性利率]](实际中性利率)
- **π** = 当前通胀率;**π\*** = 通胀目标(通常 2%)
- **y** = 实际产出;**y\*** = 潜在产出;**(y − y\*)** = 产出缺口
- **0.5、0.5** = 对"通胀偏离"和"产出缺口"的反应权重(泰勒 1993 原始取值)

## 直觉
给央行一个"该把利率定在哪"的**机械参考线**:
- 通胀超目标 → 加息;经济过热(正缺口)→ 加息;反之降息。
- 注意基准是 **r\* + π\***(= 中性名义利率);通胀、产出每偏离一点,就在此基础上加减。

## 为什么这里关键
它把 [[中性利率|r*]] 摆在公式正中央——**r\* 估高了或低了,整条参考线就移位**。这正是 [[推演-Warsh的降息缩表的路径为何]] 里"r\* 到底升没升"决定一切的另一种说法。
