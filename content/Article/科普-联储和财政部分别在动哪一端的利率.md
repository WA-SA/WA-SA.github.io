这篇是科普文, 把至今为止(2026)财政部拍卖、美联储买债/缩表、管理利率、回购等一堆操作,**逐个对到它影响曲线的哪一端**,并接上对应词条。

## 0. 先记住一张分解图
判断任何操作"动哪端",先回到 [[利率]]曲线的拆解:

> **短端 ≈ 美联储直接设定**(政策 / 管理利率)
> **长端 = 预期未来短端路径(≈ [[中性利率|r*]] + 通胀预期) + [[期限溢价]]**

所以:**谁能动"政策/管理利率",动的是短端;谁能动"预期"或"期限溢价",动的是长端。** 
下面每个工具都按这把尺子归位。

## 1. 财政部拍卖(供给侧:发什么期限,压哪端)
财政部不定利率,但它**决定卖多少、卖什么期限**——这是纯粹的"供给"力量。

- **发 [[国库券]](T-Bills,≤1 年)** → 主要压**短端**:增加短端供给、抽走货币市场的现金(也和 [[ON RRP]] 抢钱)。[[票息|无票息]]、贴现。
- **发中长期 [[国债]](T-Notes / T-Bonds,带 [[票息]])** → 主要压**长端**:给市场塞 [[久期]],推高 [[期限溢价]] → 长端 [[利率]]上行。
- **发债结构本身就是杠杆**:财政部在"多发短(bills)还是多发长(coupon)"之间的选择,会直接改变长端压力——多发短=少给市场久期=帮长端"减压"(这就是所谓"积极发债管理")。

> 一句话:**财政部发短债压短端、发长债压长端;它的"期限菜单"是影响曲线形状的隐形之手。**

## 2. 美联储——数量工具(资产负债表:主攻长端 + 水管)
- **QE(买中长期 [[国债]]/MBS)** → 把**久期**从市场抽走 → **压扁 [[期限溢价]]** → **长端**下行。
- **QT / 缩表(停止再投资、让债到期滚下)** → 久期还给市场 → 期限溢价回归 → **长端**上行。
- **准备金管理购买(2025 年底起,专买 [[国库券]])** → 目的只是**补准备金、修短端水管**,**故意买短钱、不碰长端**,以免被读成 QE(见 [[美联储准备金框架]] 发展史)。

> 一句话:**美联储的资产负债表主要是"长端工具";但它买短债续命时,动的是短端流动性,不是长端信号。**

## 3. 美联储——价格工具(管理利率:钉死短端)
- **联邦基金目标区间**:政策利率锚,直接定**短端**。
- **[[IORB]](付给银行)**:[[地板系统]]的主梁,给短端托底。
- **[[ON RRP]](付给货基等非银)**:把地板**延伸到非银**,是短端的下沿。

> 一句话:**这三个利率 = 美联储直接焊死"短端地板"的工具,和资产负债表完全是两条线。**

## 4. 回购市场(短端的下水道)
- [[回购利率|回购]](SOFR)是短期资金的水管;**[[ON RRP]] 给它兜底**。
- 准备金被抽太干,这里**最先爆**:2019 年 9 月回购利率飙到约 10%——所以回购是"短端松紧"的体温计(见 [[美联储准备金框架]])。

> 一句话:**回购利率是短端,而且是短端里最敏感的报警器。**

## 5. 市场预期(长端的另一半)
长端不是央行直接钉的,它一半看**预期**:
- 市场对未来政策利率路径的预期(本质是对 [[中性利率|r*]] 和通胀的判断)→ 决定长端里的"预期短端路径"那块。
- 对 [[真实利率]] / [[名义利率]] 的拆解、对可信度的信任,决定 [[期限溢价]]是"健康的"还是"恐慌的"。

> 一句话:**央行能钉短端,但长端要市场点头;长端 = 预期 + 期限溢价。**

## 6. 汇总表:谁动哪一端

| 操作 / 工具 | 主要影响 | 机制 | 相关词条 |
|---|---|---|---|
| 财政部发 [[国库券]](bills) | **短端** | 增加短端供给、抽现金 | [[国库券]] [[票息]] |
| 财政部发中长期 [[国债]](coupon) | **长端** | 塞久期 → 抬 [[期限溢价]] | [[国债]] [[期限溢价]] |
| 美联储 QE(买长债) | **长端↓** | 抽久期 → 压期限溢价 | [[期限溢价]] [[美联储准备金框架]] |
| 美联储 QT(缩表) | **长端↑** | 久期还市场 | [[推演-Warsh的降息缩表的路径为何]] |
| 准备金管理购买(买 bills) | **短端 / 流动性** | 补准备金、不碰长端 | [[国库券]] [[美联储准备金框架]] |
| 联邦基金目标 / [[IORB]] / [[ON RRP]] | **短端** | 直接钉地板 | [[IORB]] [[ON RRP]] [[地板系统]] |
| [[回购利率\|回购]] / SOFR | **短端(最敏感)** | 资金水管,ON RRP 兜底 | [[回购利率]] |
| 市场对 r\* / 通胀的预期 | **长端** | 预期短端路径 + 期限溢价 | [[中性利率]] [[真实利率]] |

## 7. 一句话总览
- **短端**:被**美联储(管理利率)**和**财政部(发短债)**两只手直接按住,回购市场是它的报警器。
- **长端**:没人能直接钉,它是**预期(r\*+通胀)+ [[期限溢价]]**的合成——而期限溢价又被**财政部发长债(加)**、**美联储 QE/QT(减/加)**反复拉扯。

这也正是 [[推演-Warsh的降息缩表的路径为何]] 的全部张力来源:**Warsh 想用"管理利率"管短端、用"资产负债表"管长端,两端分开打。**
